# 🧱 Догони меня, кирпич! (Catch Me, Brick!)

[![Godot Engine](https://img.shields.io/badge/Godot-v4.3%2B-478cbf?logo=godotengine&logoColor=white)](https://godotengine.org)
[![Release](https://img.shields.io/github/v/release/coca-in-a-cola/kirpych?color=f97316)](https://github.com/coca-in-a-cola/kirpych/releases/latest)

[![License](https://img.shields.io/badge/License-CC0_1.0-blue.svg)](LICENSE)

Комедийный хардкорный 3D physics-платформер на движке **Godot 4**. Игрок управляет ожившим красным терракотовым кирпичом, который неотступно преследует строителя в желтой каске по опасной стройплощадке. Главная цель — набрать колоссальную кинетическую энергию и ударить по каске с максимальной скоростью!

---

## 🎯 Ключевые особенности и философия геймдизайна

* **Инерция и скольжение**: Кирпич тяжелый и неповоротливый (3.5 кг). Кнопки управления прикладывают лишь слабое корректирующее ускорение — основная скорость набирается гравитацией на спусках, желобах и разгонных конвейерах.
* **Честный Air Control (GDD §2.3)**: Управляющее ускорение в воздухе в точности равно наземному. Никаких искусственных ослаблений или скрытых вспомогательных магнитов.
* **Декоративный переворот 360°**: Кувырок кирпича при прыжке (Пробел) изолирован на визуальной дочерней ноде (`VisualRoot`). Он не крутит физический коллайдер и не ломает стабильность симуляции.
* **Сложность в духе Getting Over It**: В игре нет чекпоинтов внутри уровня. Ошибки в прыжках приводят к реальным физическим откатам на нижние ярусы без моментальной гибели.
* **Метрика финала**: Главный показатель победы — зафиксированная скорость финального удара кирпича о каску строителя (в км/ч) с начислением рангов (от `C` до легендарного `S+ «Гроза строителей»`).

## 🗺️ Трилогия уровней

1. **Уровень I: «Рабочая смена» (Строительный двор)**
   * Старт на помосте (+12м), гравитационный спуск 22°, стопка амортизирующих покрышек (+9.5 м/с вверх, +14 м/с вперед), скользкий тент (трение 0.05, разгон до 60 км/ч) и финиш у двери.
   * *Топографический план*: [`docs/level_design/LEVEL_01_SPEC.md`](docs/level_design/LEVEL_01_SPEC.md) | [Векторная карта](assets/maps/level_01_map.svg).
2. **Уровень II: «Нарушение ТБ» (Вертикальный недострой)**
   * 3 этажа железобетонного монолита (перепад 20м), промышленный конвейер (+16 м/с), грузовой подъемник, бетонный желоб, лифтовые шахты и тяжелая металлическая дверь с порогом пробития 35 км/ч.
   * *Топографический план*: [`docs/level_design/LEVEL_02_SPEC.md`](docs/level_design/LEVEL_02_SPEC.md) | [Векторная карта](assets/maps/level_02_map.svg).
3. **Уровень III: «Высотные работы» (Кровля и кран — Гранд-финал)**
   * Открытая кровля на высоте 28–38м, узкая балка 1.2м, промышленный вентилятор с восходящим потоком (+22 м/с² Y, +12 м/с² Z), раскачивающийся маятниковый кран и финальный прыжок к фасадной люльке.
   * *Кульминация*: Удар по каске над люлькой, драматичное слоу-мо (0.25x), звонкий «ДЗЫНЬ!» и комичное безопасное падение строителя в натянутую страховочную сетку.
   * *Топографический план*: [`docs/level_design/LEVEL_03_SPEC.md`](docs/level_design/LEVEL_03_SPEC.md) | [Векторная карта](assets/maps/level_03_map.svg).

## ⌨️ Управление (Только ПК)

| Клавиша | Действие | Описание |
| :--- | :--- | :--- |
| **W / A / S / D** | Руление | 4 дискретных направления (арбитраж по последней нажатой клавише) |
| **Пробел (Space)** | Прыжок | Одиночный физический импульс с декоративным кувырком 360° |
| **R** | Рестарт | Мгновенный сброс текущего уровня |

## 🚀 Запуск и тестирование

### Вариант 1: Через Godot 4 Editor
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/coca-in-a-cola/kirpych.git
   ```
2. Откройте проект в Godot 4.3+ и нажмите **Play** (`F5`). Главное меню загрузится автоматически.

### Вариант 2: Запуск готового релиза (Standalone PCK)
Скачайте бинарный пакет `kirpych-v0.1.0-linux.pck` со [страницы релизов](https://github.com/coca-in-a-cola/kirpych/releases/latest) и запустите через движок:
```bash
godot4 --main-pack kirpych-v0.1.0-linux.pck
```

### Запуск автономных headless-тестов
Проект укомплектован 100% покрытием интеграционными сценариями, не требующими графического окружения:
```bash
# Тест физики и механик Уровня 1 (5 тестов)
godot4 --headless --script res://tests/test_brick_physics.gd

# Тест конвейеров, подъемников и двери Уровня 2 (4 теста)
godot4 --headless --script res://tests/test_level_02.gd

# Тест аэродинамики вентилятора, маятника и слоу-мо Уровня 3 (4 теста)
godot4 --headless --script res://tests/test_level_03.gd

# Тест главного меню, переходов и подсчета рейтинга кампании (3 теста)
godot4 --headless --script res://tests/test_campaign_flow.gd
```

## 📁 Структура проекта

```text
kirpych/
├── assets/
│   ├── audio/          # Синтезированные 44.1kHz WAV-сэмплы (каска, шины, прыжок, трение)
│   ├── maps/           # 2D топографические векторные карты уровней (SVG)
│   └── materials/      # Набор PBR-материалов (терракота, каска, резина, бетон, фанера)
├── docs/
│   ├── GDD_v0.4.md     # Мастер-спецификация геймдизайна из Notion
│   ├── ASSET_MANIFEST.md # Манифест лицензий и происхождения ассетов
│   └── level_design/   # Подробные ТЗ по каждому уровню
├── src/
│   ├── camera/         # Сплайновая камера со сглаживанием и динамическим FOV
│   ├── entities/       # Игрок (Brick), Рабочий (Worker), Пропсы (Шины, Тенты, Двери, Краны)
│   ├── levels/         # 3D сцены уровней (level_01, level_02, level_03)
│   ├── scripts/        # Менеджер кампании (GameManager) и контроллер ввода
│   └── ui/             # Главное меню (MainMenu) и игровой HUD со спидометром
├── tests/              # Автоматизированный headless тестовый набор
└── project.godot       # Конфигурация движка Godot 4
```
